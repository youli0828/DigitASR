# 实现说明

## M1：信号处理与接口

包使用 src 布局。soundfile 读取 WAV，多声道平均为单声道，SciPy 多相滤波重采样到 16 kHz。
拒绝空音频、静音、非有限值；去掉首尾低于峰值 1% 的近静音并归一化。
预加重系数 0.97，25 ms 帧长、10 ms 帧移，末帧补零。
对相同帧分别应用对称 Hamming 或 Hann 窗，512 点 FFT，40 个 Slaney mel 滤波器，
功率转 dB 后作 DCT 获得 13 维 MFCC。整个特征流程实际调用包内分帧/加窗实现。

每条语音输出 78 维：全句 MFCC 均值/标准差（26）和四个等时段的 MFCC 均值（52）。
超短语音对 MFCC 时间轴插值到至少四帧，保证接口维数；这不代表它具有可识别内容。
不包含文件名、标签、语速或音高元数据。测试时使用训练保存的同一 FeatureConfig。

## M2：模型和实验

SVM 是 StandardScaler + RBF SVC（C=10，gamma=scale），缩放器仅拟合训练集。
随机森林固定 200 棵树、种子 42、单线程。超参数预先固定，没有使用测试集选择。
共运行 2 模型 × 2 窗函数。模型 artifact 内保存估计器、特征配置、训练路径和数据指纹。

清单必须覆盖训练集和测试集的十个类别。读取时检查路径边界、重复路径、跨集相同内容和
跨集相同来源组。数据指纹包含 WAV 内容哈希、路径、标签、划分和组；评估要求与训练一致。
这防止意外换数据后引用旧模型指标；替换语料应重新训练。新增语料可按录制指南创建清单。
joblib 仅用于可信本地产物，加载不可信文件可执行代码。

指标使用 sklearn：accuracy、固定 0–9 顺序的混淆矩阵、逐类 precision/recall/F1/support。
CSV 额外保存逐条预测和四组汇总，便于核验。没有用训练集准确率代替测试集准确率。
目前样例只有一个共振峰合成音色；真人语音与跨人泛化尚未验证。

## M3：Demo 与工程

Gradio 上传/录音得到路径，DigitRecognizer 使用相同加载和特征接口预测，页面可切换四个模型。
默认仅监听 127.0.0.1，不启用公网分享。缺失模型时提示先训练，不在网页请求内隐式训练。
CI 在 Linux 的 Python 3.10/3.12/3.14 上安装包、运行 ruff 和 pytest；本地验证以 RESULTS.md
记录为准，不声称远程 CI 已执行。没有初始化 Git 或创建提交。

未实现 ONNX、连续语音或移动端功能。

## 12. 轻量 CNN 基线与真实数据对比

可选 `.[torch]` 启用 3,914 参数的 1D CNN；默认安装、SVM 加载与推理不导入 torch。
CNN 共用预处理和 Hamming MFCC 提取，保留 13×64 时序输入；旧特征默认仍输出 78 维。
卷积核依次为 5/3，通道 16/32，中间最大池化，末尾四段平均池化后线性分类。
输入按训练集的 MFCC 通道均值和标准差归一化，统计量与网络一起保存到可信本地 joblib。

`run_cnn_comparison.py` 调用与现有真实数据 SVM 相同的 `prepare_gitcode_manifest`：
seed=42 打乱唯一 SHA-256 的组 ID 后，取 `StratifiedGroupKFold(5, shuffle=False)` 首折。
同一份 rows 同时供两个模型使用；训练 200 条、测试 50 条，重复音频不跨集合。
共享划分及数据指纹保存在 `reports/cnn/`，每个模型单独导出指标、混淆矩阵和逐条预测。
这修正了旧报告方法文字的歧义；实际分组实现和原报告的数据指纹保持一致。

训练参数预先固定：CPU 单线程，100 epochs，batch=32，Adam lr=0.003、weight_decay=1e-4。
无测试集调参、早停或选模。真实 GitCode 实测 SVM 50/50、CNN 49/50，不能据此声称 CNN 更优，
也不能声称说话人隔离。合成数据只用于离线测试，不作为这里的主比较结果。
CLI 训练支持 cnn / svm_hamming；保存后的模型可由现有评估和 DigitRecognizer 接口直接使用。
